One long-running crucibo process polls market data, loads the aapl_mlp_v1 model weights, and simulates fills. No shell commands per bar. No Cursor agent loop required.
Reading this page — top-right status tells you the mode. Decision bars counts how many market bars the model has judged (not live ticks). PnL is simulated profit vs $1M start (cash + stock value − $1,000,000). A red PnL with no fill usually means holding shares while price moved, not a sale loss. Fills are simulated buys/sells only. Activity is the event log.
